# nabrowse-layout

Layout engine for NaBrowse: box model, block layout, inline layout.

Takes the DOM tree and computed styles, and produces pixel rectangles for
every layout box.

## Features

- CSS box model (margin, border, padding, content)
- Block layout (normal document flow)
- Inline layout (basic text lines)
- Layout tree with concrete pixel geometry
