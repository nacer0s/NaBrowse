# nabrowse-shared

Shared geometry and core types for NaBrowse.

## Types

- `Point` — 2D point (f32).
- `Size` — 2D size (f32).
- `Rect` — rectangle with intersection and edge helpers.
- `Color` — RGBA color (0.0..=1.0).
- `EdgeInsets` — padding/margin insets.
- `NabrowseUrl` — lightweight URL wrapper.
